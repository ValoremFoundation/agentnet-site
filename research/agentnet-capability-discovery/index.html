How AI Agents Discover and Buy Capabilities on AgentNet

AgentNet is built so an autonomous agent can find a capability, verify its machine contract, and pay for it over x402 — without a human in the loop.

The discovery surfaces

Three machine-readable surfaces: llms.txt (compact), agentnet-catalog.json (full JSON), and the canonical capability HTML pages (each with JSON-LD Service schema). Any of these is enough for an agent to build a shopping list.

The machine contract

Every capability record declares its provider, availability (sellable now vs. planned), HTTP endpoint, method, and x402 price in USDC. That is the whole contract — no hidden terms.

Paying over x402

The agent calls the endpoint, receives a 402 payment requirement, signs the USDC payment on Base, resends, and receives the payload. The tx hash plus the response is durable proof of purchase.

Why one catalog

A single canonical catalog means every provider, capability, price, and state agrees. Agents don't reconcile multiple sources; they read the one source of truth.

Frequently asked questions

Which agents can use AgentNet today?
Any HTTP client with a Base wallet. GPT-style, Perplexity, Claude, and custom agents all work with the same x402 handshake.
